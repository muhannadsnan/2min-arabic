# Days 26–29 — Lina's lines (Koki)

### 🎬 Scene 1 — lines

```say:lina
لَا، سَهْلْ!
```
```say:lina
كَمْ عُمْرُكْ؟
```
```say:lina
أَيْنَ تَسْكُنُ؟
```
```say:lina
مَاذَا تَدْرُسُ؟
```
```say:lina
مُمْتَازْ!
```
```say:lina
هَذَا هُوَ الِامْتِحَانْ!
```
```say:lina
مَرْحَبًا!
```
```say:lina
كَيْفَ حَالُكْ؟
```
```say:lina
بِخَيْرْ. مَا اسْمُكْ؟
```
```say:lina
مِنْ أَيْنَ أَنْتَ؟
```
```say:lina
هَلْ أَنْتَ طَالِبْ؟
```
```say:lina
هَلْ تُرِيدُ قَهْوَةْ؟
```
```say:lina
مَعَ السَّلَامَةْ!
```
```say:lina
بِخَيْرْ، الْحَمْدُ لِلَّهْ. وَأَنْتَ؟
```
```say:lina
اسْمِي لِينَا.
```
```say:lina
نَعَمْ، أَنَا طَالِبَةْ.
```
```say:lina
لَا، أُرِيدُ شَايْ!
```
