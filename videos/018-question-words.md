# Day 18 — Phrases: the 5 question words (Lina asks, Sami answers)

| | |
|---|---|
| **Format** | Phrases (5 question words, each one asked by Lina and answered by Sami at once) |

| **Goal** | The viewer knows what · who · where · how many · when, hears each one in a real question, and asks one in "Your turn". |
| **New words** | مَا (what) · مَنْ (who) · أَيْنَ (where) · كَمْ (how many) · مَتَى (when) · هُنَا (here) · الْآنْ (now) · فِنْجَانْ in a question · دَرْسْ (lesson) |
| **Re-used (due)** | هَذَا / هَذِهِ · كِتَابِي (Day 12–13) · أُخْتِي · قِطّ (Day 13) · ثَلَاثَةْ (Day 10) · الشَّايْ (Day 17, "Your turn") · sun letter in الدَّرْسْ (Day 17) |
| **Voices** | English narrator = owner's clone (tempo 0.9) · Arabic = the owner (teacher, Sami) + Koki (Lina) → **AI label: No** |
