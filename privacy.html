Privacy policy

Last updated: 18 October 2026

“2min tools” is a personal tool used only by the owner of the 2 Minute Arabic channel to manage that one YouTube channel.

YouTube API Services

This tool uses YouTube API Services (YouTube Data API and YouTube Analytics API). By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool does

  • Who uses it: only the channel owner. No other users can sign in.
  • What it accesses: the owner's own YouTube channel through the YouTube Data API and YouTube Analytics API: video details, subtitles, playlists, comments on the channel's own videos, and the channel's own statistics.
  • Where data is kept: the sign-in token is stored only on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising.
  • Cookies and tracking: the tool and this website use no cookies, tracking or analytics of visitors.

Data retention and deletion

  • The tool keeps no database of YouTube data. Data it reads is used at once (for example to fill in a video's details or upload subtitles) and is not kept.
  • Short summaries of the channel's own statistics are kept in the owner's private notes for the weekly review and can be deleted at any time.
  • Revoking access: access can be revoked at any time at myaccount.google.com/permissions (Google security settings). After revoking, the tool can no longer access the channel, and the stored sign-in token is deleted within 7 days.
  • Deletion requests: contact the owner through the channel; any stored data is deleted within 7 days.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
